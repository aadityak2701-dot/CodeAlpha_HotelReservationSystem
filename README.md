# CodeAlpha - Hotel Reservation System

### Task 4 - Java Internship

A Java Swing based Hotel Reservation System.

**Features:**
- Search Rooms by Category (Deluxe, Standard, Suite)
- Book Room with Customer Name
- Payment Simulation (Confirm Dialog)
- Cancel Booking
- View All Bookings
- OOPs Concepts & File Handling

**Tech Stack:** Java, Swing, ArrayList, JFrame

**How to Run:**
javac HotelReservation.java
java HotelReservation
